# Yunqing Zhao

I'm an AI researcher based in Singapore, working on multimodal models, agents, and media generation.

My research asks how models learn from limited data, how they hold up against untrusted or adversarial inputs, and how they use tools to gather evidence before they answer.

### Selected works

- [**CodeDance**](https://github.com/CodeDance-VL/CodeDance) — Think with image through code, with adaptive tool use. *CVPR*

- [**GenLIP**](https://github.com/YanFangCS/GenLIP) — Generative multimodal pre-training. *ECCV*

- [**Text4Seg++**](https://arxiv.org/abs/2509.06321) — Vision tasks recast as generative language modeling. *TPAMI*
  
- [**AdAM**](https://yunqing-me.github.io/AdAM/) — Adaptive parameter-efficient generative fine-tuning. *NeurIPS*
  
- [**AttackVLM**](https://yunqing-me.github.io/AttackVLM/) — Frontier risk evaluation for VLMs with pixel-only, black-box targeted attack. *NeurIPS*
  
- [**ThinkGen**](https://github.com/jiaosiyuu/ThinkGen) — Reasoning for visual generation. *CVPR*
  
- [**Pistis Tech report**](https://pististeam.github.io/) — Multimodal foundation and reasoning models, agents and long-horizon tasks. *Tech Report*
